### BUG C: SIM Trading in All Regimes ✅

**Problem:**
```
⚠️ [SIM MODE] Trading in ALL regimes (RISKY!)
```
SIM mode automatically overriding regime rules.

**Root Cause:**
- Automatic `SIM_TRADE_IN_BEAR` flag enabling trading in all regimes
- SIM not behaving like LIVE

**Fix:**
- Replaced with `SIM_IGNORE_REGIME` flag (default: `false`)
- SIM now respects regime rules by default (same as LIVE)
- Must explicitly enable override if desired

**Files to Update:**
- `v3/regime/detector.py` - Update `should_trade_longs()` method
- `.env.example` - Add `SIM_IGNORE_REGIME=false`

**Example Fix:**
```python
def should_trade_longs(self) -> bool:
    """Should we take long positions in this regime?"""
    # BUG FIX: SIM must behave EXACTLY like LIVE by default
    ignore_regime = os.getenv('SIM_IGNORE_REGIME', 'false').lower() == 'true'

    if ignore_regime:
        print("⚠️  [WARNING] SIM_IGNORE_REGIME=true - Trading in ALL regimes (RISKY!)")
        return True

    # Normal: Only trade in BULL or SIDEWAYS
    return self.current_regime in [Regime.BULL, Regime.SIDEWAYS]
```

#### 1. Trend Filter
- `trend_ratio_4h >= 1.03`
- `EMA20_4h > EMA50_4h`

#### 2. Outperformance Filter
- **RS vs BTC (14d) > +5%**

#### 3. Sweet Spot Filter
- **24h return: +5% to +40%**
- Not too cold, not parabolic

#### 4. Volume & Liquidity Filter
- **RVOL >= 1.5** (relative volume)
- **Spread <= 1.0%**
- **Depth >= $10,000** (orderbook depth at 10 levels)

#### 5. Structure Filter
- **price_pos_24h: 0.5 to 0.9** (price position in 24h range)
- **3d_return < +80%** (no parabolic moves)
- **No blowoff candles** (15m body > 3×ATR)

### Entry Trigger:
- `close > 24h_high × 1.003` (breakout confirmation)
- **Higher lows recent** (structure confirmation)

### Exit Strategy:
- **Stop Loss:** max(1.5 × ATR15m, swing low)

- **Trailing Stop:** highest - 1.0 × ATR
- **NFT Rule:** 3 hours / 0.5R MFE (no favorable trade exit)

### 1. v3/data/mexc_client.py

Add this method to the `MexcClient` class:

```python
def get_ticker_24h(self, symbol: str) -> Optional[Dict]:
    """
    Get 24h ticker data for a single symbol

    Returns ticker dict with lastPrice, priceChangePercent, etc.
    """
    params = {'symbol': symbol}
    data = self._request("/api/v3/ticker/24hr", params=params)

    if data is None:
        return None

    # MEXC returns single dict for single symbol query
    if isinstance(data, dict):
        return data

    # Sometimes returns list with single element
    if isinstance(data, list) and len(data) > 0:
        return data[0]

    return None
```
