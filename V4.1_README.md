## 🐛 Troubleshooting

### Status still shows zeros?
```bash
# Check if mexc_client has get_ticker_24h method
python3 -c "from v3.data.mexc_client import mexc_client; print(hasattr(mexc_client, 'get_ticker_24h'))"
```

### Scanner still failing?
```bash
# Check error logs
grep "Failed to fetch" logs/scanner.log
```

### Bear-resilient engine not activating?
```bash
# Check configuration
cat .env | grep ENABLE_BEAR_LONGS

# Check regime
python3 -c "from v3.regime.detector import regime_detector; print(regime_detector.current_regime)"
```
