# V4.1 Implementation Fixes - November 21, 2025

## Summary

This update implements **R-based position sizing** throughout the V4.1 codebase, replacing the inconsistent hardcoded 20% position sizes. All risk calculations now use the `RISK_PER_TRADE_*` values from `.env`.

---

## Files Changed

### 1. `v3/scanner/signals.py`

**Changes:**
- Removed hardcoded `size_usd = equity * 0.20` from `_generate_long_signal()` and `_generate_short_signal()`
- Signals now only specify: entry_price, stop_loss, direction, engine, regime
- Size calculation is delegated to `risk_engine`
- Changed engine tags from `'standard'` to `'standard_long'` and `'standard_short'` for clarity

**Before:**
```python
size_usd = equity * 0.20  # 20% of equity
signal = {..., 'size_usd': size_usd, ...}
```

**After:**
```python
# NOTE: size_usd is calculated by risk_engine based on R
signal = {...}  # No size_usd - risk_engine calculates it
```

### 2. `v3/risk/risk_engine.py`

**Major Rewrite - Key Changes:**

1. **R-based Position Sizing:**
   ```python
   def calculate_position_size(self, signal, equity):
       stop_distance_pct = (entry - stop) / entry
       risk_pct = self.get_risk_per_trade(regime, engine)
       initial_risk_usd = equity * risk_pct  # This is "R"
       size_usd = initial_risk_usd / stop_distance_pct
   ```

2. **Portfolio Heat in R-terms:**
   ```python
   def _calculate_portfolio_heat(self, equity):
       total_risk_usd = sum(pos.initial_risk_usd for pos in positions)
       return total_risk_usd / equity  # Heat = sum(R) / equity
   ```

3. **Position Class Updates:**
   - Added `initial_risk_usd` field (the R value)
   - Added `regime` field
   - Added `highest_price` for trailing stops
   - Added `remaining_size_pct` for partial exits

4. **Engine-specific Risk:**
   ```python
   def get_risk_per_trade(self, regime, engine):
       if engine == 'bear_resilient_long': return RISK_PER_TRADE_BEAR_LONG
       elif engine == 'standard_short': return RISK_PER_TRADE_BEAR_SHORT
       elif regime == 'BULL': return RISK_PER_TRADE_BULL
       else: return RISK_PER_TRADE_SIDEWAYS
   ```

5. **SPOT Market Protection:**
   ```python
   if self.market_type == 'SPOT' and direction == 'SHORT':
       return (False, "SPOT market: cannot short", 0, 0)
   ```

6. **open_position() now takes equity:**
   ```python
   def open_position(self, signal, equity):  # equity is now required
   ```

## Configuration Notes

### Required .env Settings

```bash
# Risk per trade (fraction of equity)
RISK_PER_TRADE_BULL=0.003       # 0.30% risk in BULL
RISK_PER_TRADE_SIDEWAYS=0.0025  # 0.25% risk in SIDEWAYS
RISK_PER_TRADE_BEAR_SHORT=0.0012 # 0.12% risk for shorts
RISK_PER_TRADE_BEAR_LONG=0.0008  # 0.08% risk for bear micro-longs

# Portfolio limits (R-based)
MAX_PORTFOLIO_HEAT=0.015  # 1.5% total risk across all positions

# Market type
MARKET_TYPE=SPOT  # or FUTURES
```

### Math Example

For a SIDEWAYS regime with $500 equity:
- RISK_PER_TRADE = 0.0025 (0.25%)
- R = $500 × 0.0025 = **$1.25**
- If stop is 3% below entry: size = $1.25 / 0.03 = **$41.67**
- MAX_PORTFOLIO_HEAT = 0.015 (1.5%)
- Max total R = $500 × 0.015 = **$7.50**
- Max positions at full risk = $7.50 / $1.25 = **6 positions**

## Breaking Changes

1. **`risk_engine.open_position()` signature changed:**
   - Old: `open_position(signal)`
   - New: `open_position(signal, equity)`

2. **Signals no longer include `size_usd`:**
   - Any code expecting `signal['size_usd']` will break
   - Size is now calculated by risk_engine

3. **Position requires `initial_risk_usd`:**
   - Old positions without this field will default to `size_usd * 0.03`
