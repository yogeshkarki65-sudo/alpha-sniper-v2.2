## %Risk Sizing Implementation

Position sizing is now **100% R-based** using `RISK_PER_TRADE_*` from .env.

### Formula

```python
# For each new trade:
risk_pct = RISK_PER_TRADE_* from .env (based on regime/engine)
risk_dollars = equity * risk_pct
sl_distance_pct = abs(entry_price - stop_loss) / entry_price
size_usd = risk_dollars / sl_distance_pct
```

### Risk Parameters (from .env)

| Regime/Engine | Risk per Trade | Example ($500 equity) |
|---------------|----------------|----------------------|
| BULL | 0.30% | $1.50 at risk |
| SIDEWAYS | 0.25% | $1.25 at risk |
| BEAR_SHORT | 0.12% | $0.60 at risk |
| BEAR_LONG | 0.08% | $0.40 at risk |

### Portfolio Heat

- `MAX_PORTFOLIO_HEAT = 0.015` (1.5%)
- Calculated as: sum(initial_risk_usd) / equity
- Prevents over-concentration of risk

### Key Implementation Files

1. **signals.py** - Sets entry_price, stop_loss (ATR-based), take_profit
   - Does NOT set size_usd (delegates to risk_engine)

2. **risk_engine.py** - Calculates R-based position size
   - `calculate_position_size()` uses RISK_PER_TRADE_* from .env
   - Enforces portfolio heat limits
   - Stores `initial_risk_usd` in Position object

## Scanner Interval Safety

V4.1.1 adds safety bounds to prevent misconfiguration:

```python
MIN_SCANNER_INTERVAL = 60    # Minimum 60 seconds
MAX_SCANNER_INTERVAL = 3600  # Maximum 1 hour
DEFAULT_SCANNER_INTERVAL = 300  # 5 minutes (optimal from backtest)
```

- 5-minute scanning is the sweet spot (higher WR, fewer whipsaws)
- 1-minute scanning is noisier with lower WR
- Values outside bounds are automatically clamped with a warning
